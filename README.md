This is an extension for the Addon [Shadowed Unit Frames](https://www.curseforge.com/wow/addons/shadowed-unit-frames-redux). It is required for this Addon to have any effect.



This will add a new feature to the player power bar. It displays a moving indicator that moves across the power bar for 5 seconds after the player has spent mana. In classic versions of the game the player is subject to reduced mana regeneration for 5 seconds after they cast a spell. This helps the player to better visualize this window and manage their mana.
